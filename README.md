# YouTube Mobile Fix

Скрипт для мобильного YouTube в браузере (Safari на iPhone, Firefox на Android).

## Что умеет

- **Выключает субтитры** на каждом видео (и прячет их, если YouTube всё равно включит).
- **Круглая кнопка меню** в правом нижнем углу (через пару секунд становится полупрозрачной, чтобы не мешать). В меню:
  - **Для тебя** — отдельный список твоих рекомендаций с превью, длительностью и каналом. Фильтры «Любые / От 10 мин / От 30 мин», кнопка «Обновить» загружает свежую подборку. Уже начатые видео скрыты.
  - **Таймер сна** — 15 / 30 / 45 / 60 / 90 минут. Пока таймер идёт, на кнопке меню видно, сколько минут осталось. Когда время выйдет, видео встанет на паузу. Таймер не сбрасывается, когда видео переключается.
  - **На весь экран / Повернуть влево / Повернуть вправо** (на странице видео) — видео открывается в отдельном слое поверх страницы со своими кнопками: пауза, ±10 секунд, полоска перемотки, смена поворота, закрыть.
- Пытается убрать полоску Safari **«Открыть в приложении YouTube»**.
- Чинит «съехавшую» вбок страницу.
- По желанию — тёмно-зелёный фон (`greenTheme: true`).

## Как смотреть лёжа на боку (iPhone)

1. Включи **блокировку поворота** (замочек в Пункте управления) — экран перестанет крутиться сам.
2. Открой видео → кнопка меню → **Повернуть влево** или **Повернуть вправо**.
3. Если картинка вверх ногами — нажми другой поворот прямо в плеере (кнопки вверху). Крестик — вернуться обратно.

## Важно знать честно

- **В официальное приложение YouTube расширения поставить нельзя.** Скрипт работает только на сайте в браузере.
- Сайт не может управлять поворотом экрана iPhone — поэтому поворачивается само видео.
- Полоску «Открыть в приложении» рисует Safari. Если Safari успеет её показать раньше скрипта, она останется.
- YouTube периодически меняет свой код, поэтому со временем что-то может потребовать обновления.

## Установка на iPhone

1. Установи из App Store **Userscripts** и один раз открой его.
2. Настройки → Приложения → Safari → Расширения → **Userscripts** → включить, для сайтов выбрать «Разрешить».
3. Открой в Safari ссылку https://raw.githubusercontent.com/Daxxverr/youtube-mobile-fix/main/youtube-mobile-fix.user.js → **≡** → **Userscripts** → **Install**.
4. Открой YouTube в Safari, при запросе разреши Userscripts работать на youtube.com.

## Установка на Android

1. Установи **Firefox** → Дополнения → **Violentmonkey**.
2. Открой ссылку https://raw.githubusercontent.com/Daxxverr/youtube-mobile-fix/main/youtube-mobile-fix.user.js — Violentmonkey предложит установить.

## Обновление

1. Удали старый скрипт в приложении Userscripts (или Safari → **≡** → **Userscripts**).
2. Открой ссылку на скрипт → **≡** → **Userscripts** → **Install**.
3. Проверь, что `@version` вверху кода новая. GitHub отдаёт обновлённый файл с задержкой до 5 минут.

## Если пользуешься приложением YouTube (без скрипта)

Субтитры, которые включаются сами, чаще всего включены на уровне системы:

- **Android:** Настройки → Спец. возможности → Настройки субтитров → выключить.
- **iPhone:** Настройки → Универсальный доступ → Субтитры → выключить «Скрытые субтитры + SDH».

## Настройки скрипта

Вверху файла есть блок `SETTINGS`:

```js
disableCaptions: true,           // выключать субтитры
hideCaptionsWithCss: true,       // прятать субтитры через CSS
showMenuButton: true,            // кнопка меню
recsSkipWatched: true,           // «Для тебя»: скрывать уже начатые видео
recsDefaultMinMinutes: 0,        // «Для тебя»: фильтр длины по умолчанию (0, 10 или 30)
sleepOptions: [15, 30, 45, 60, 90], // варианты таймера сна
removeAppBanner: true,           // убирать «Открыть в приложении»
greenTheme: false,               // тёмно-зелёный фон вместо чёрного
fixLayout: true,                 // чинить сдвиг страницы
fullscreenOrientation: 'landscape' // Android: ориентация в полноэкранном режиме
```
